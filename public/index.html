⚠ Outlook needs 3 things before SMTP works:
  1. Step 1 — Enable 2-Step verification:
    → account.microsoft.com/security → Turn on 2-step verification
  2. Step 2 — Enable SMTP AUTH for your mailbox:
    → Outlook Settings → Mail → Sync email → Enable SMTP
  3. Step 3 — Create an App Password:
    → account.microsoft.com/security → Advanced security → App passwords → Create new → copy & paste above
💡 Easier option: Use Gmail instead — just enable 2FA and create an App Password.
4-Step Microsoft App Setup:
  1. Open Microsoft Entra App registrations ↗
  2. Click New registration → Name: SmartMail Pro → Select "Accounts in any organizational directory and personal Microsoft accounts".
  3. Under Redirect URI: Select Web and set:
    http://localhost:3000/auth/microsoft/callback
  4. Under API permissions → Add: Mail.Send, offline_access, User.Read.
  5. Under Certificates & secrets → Create New client secret and copy the Value.
